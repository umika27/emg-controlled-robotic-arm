# Demonstration and report guide

## Recommended 7-minute demonstration
1. Show `01_raw_filtered.png`, explain electrode acquisition, artifacts and band-pass response.
2. Show `05_psd.png` and `04_filter_response.png`; **do not claim verified SNR improvement**.
3. Show `03_rms_distributions.png`, explain RMS, MAV, WL, ZC, SSC, mean/median frequency and their limitations.
4. Explain homogeneous 200 ms windows, 100 ms hop, subject-disjoint splits and train-only standardization.
5. Show `results/metrics.csv` and confusion matrices **after running MATLAB**; compare binary activation and 4-class classification separately.
6. Show `08_control_tracking.png` and editable Simulink block diagram generated by `build_simulink_model`.
7. Play `09_arm_animation.gif`. Clearly describe it as a kinematic proof of concept, not a tested robot or full physical simulation.

## Architecture
```
Forearm → electrodes → EMG amplifier/ADC → digitized EMG
 → filter → homogeneous windows → {time/frequency features → RF,
                                   normalized samples → temporal CNN}
 → gesture + confidence (future integrated interface)
 → desired joint reference → PI feedback → motor/joint (simulated)
 → position feedback → 3D kinematic visualization
```

## Validation priorities before claiming completion
- Run MATLAB unit checks and independently inspect figures.
- Check empirical sampling timing across recordings and test justified resampling.
- Check that all gesture classes occur in each split (or change split seed).
- Compare offline zero-phase versus online causal filter predictions.
- Cross-check streaming replay on unseen recordings and fit thresholds only on training/calibration sets.
- Train CNN at sufficient duration and record actual metrics; test class imbalance and per-subject variation.
- Replace scripted references with actual classifier outputs and implement confidence gate/stop behavior.
- Identify actual actuator transfer function and include saturation, safe ranges, and speed limits.
